What it does for you

Less fixing. More teaching.

Every page gets checked and tidied the same way, so your book looks neat from the first page to the last.

Margins set for you

Each page gets the same margins and padding. Wide tables shrink a little or turn sideways, so nothing gets cut.

Every number looks the same

One font and one size for all numbers. Decimals line up and number columns get equal width.

See each page first

Your book shows up as real PDF pages. Look through them, change things, then download when it looks right.

Any page size

A4 to start. Switch to A5, A3, B5, Letter, Legal, square or your own size in a click.

Fun designs for kids

Rainbows, balloons, stars, clouds and crayon borders. Or upload your own background and add a watermark.

Private and free

Your Excel file never leaves your computer. The whole book is made right here in your browser.
